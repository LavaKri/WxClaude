# WxClaude

A desktop interface made for screen readers, built on the command line (CLI) of Claude Code.

WxClaude is an independent project. It is not made, endorsed or sponsored by Anthropic.
"Claude" and "Claude Code" are names of Anthropic's products.

## Requirements

- Windows 11.
- The [Claude Code](https://claude.com/claude-code) application installed.
- A Claude account with an active subscription.
